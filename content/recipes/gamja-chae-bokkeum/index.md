감자채가 떡처럼 뭉치는 건 **표면의 전분** 때문입니다. 썰고 나서 물에 두세 번 헹구면
가닥가닥 떨어져 볶입니다. 물기는 반드시 털어내세요 — 남으면 기름이 튑니다.

## 재료

{{< ingredients >}}
- 감자 2개
- 식용유 1큰술
- 물 2큰술
- 소금 1/2작은술
{{< /ingredients >}}

## 만드는 법

{{< steps >}}
1. 감자는 껍질을 벗기고 0.3cm 두께로 가늘게 채 썹니다.

2. 찬물에 담가 두세 번 헹궈 **물이 맑아질 때까지** 전분을 뺍니다. 체에 밭쳐 물기를 충분히 털어냅니다.

3. 팬에 식용유 1큰술을 두르고 중불에서 감자채를 2분 볶습니다.

4. 물 2큰술을 넣고 **뚜껑을 덮어 약불에서 3분** 익힙니다. 수증기로 속까지 익히는 단계입니다.

5. 뚜껑을 열고 소금 1/2작은술을 넣은 뒤, 중불로 올려 **남은 물기를 날리며** 2분 더 볶습니다.
{{< /steps >}}

{{< tip >}}
- 소금은 마지막에 넣으세요. 처음부터 넣으면 감자에서 물이 나와 눅눅해집니다.
- 양파 1/4개나 당근을 조금 넣으면 단맛이 더해집니다. 감자보다 먼저 넣어 볶으세요.
- 파프리카나 피망을 마지막 30초에 넣으면 색이 살아납니다.
- 아삭한 식감을 원하면 4번 단계를 2분으로 줄이세요.
{{< /tip >}}
