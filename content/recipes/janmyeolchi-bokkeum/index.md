멸치볶음이 딱딱하게 굳는 건 **올리고당을 불 위에서 졸였기** 때문입니다.
불을 끄고 잔열에서 섞으면 부드럽고 윤기만 남습니다.

## 재료

{{< ingredients >}}
- 잔멸치 100g
- 식용유 1큰술
- 간장 1작은술
- 설탕 1/2큰술
- 올리고당 1큰술
- 통깨 1/2큰술
{{< /ingredients >}}

## 만드는 법

{{< steps >}}
1. 잔멸치를 체에 쳐서 가루와 부스러기를 털어냅니다.

2. **기름을 두르지 않은 마른 팬**에 멸치를 넣고 중불에서 2분 볶습니다. 비린내가 날아가고 바삭해집니다. 볶은 멸치는 그릇에 덜어둡니다.

3. 같은 팬에 식용유 1큰술, 간장 1작은술, 설탕 1/2큰술을 넣고 **약불로** 데웁니다. 설탕이 녹으면 됩니다.

4. 덜어둔 멸치를 넣고 양념이 고루 묻도록 1~2분 볶습니다.

5. **불을 끄고** 올리고당 1큰술과 통깨를 넣어 섞습니다. 잔열로 충분히 코팅됩니다.
{{< /steps >}}

{{< tip >}}
- 3번에서 불이 세면 간장이 타서 씁니다. 반드시 약불로.
- 견과류(아몬드 슬라이스, 호두)를 2번에서 함께 볶으면 고소함이 더해집니다.
- 매콤하게 하려면 청양고추를 잘게 썰어 4번에 넣으세요. 꽈리고추볶음처럼 됩니다.
- 완전히 식혀서 밀폐용기에 담으면 냉장 2주까지 갑니다. 뜨거울 때 담으면 눅눅해집니다.
{{< /tip >}}
