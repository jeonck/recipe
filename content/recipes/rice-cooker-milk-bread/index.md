오븐 없이 밥솥으로 굽는 식빵입니다. 결과를 가르는 건 두 가지예요.
**우유 온도**와 **버터를 넣는 타이밍**. 우유가 차가우면 이스트가 안 깨어나 반죽이 안 부풀고,
버터를 처음부터 넣으면 밀가루에 기름막이 생겨 글루텐이 잡히지 않습니다.

## 재료

{{< ingredients title="반죽" >}}
- 강력분 300g
- 드라이이스트 5g
- 우유 150ml (따뜻하게)
- 계란 1개
- 연유 3큰술
- 버터 30g (녹인 것)
{{< /ingredients >}}

{{< ingredients title="마감" >}}
- 연유 약간
{{< /ingredients >}}

## 만드는 법

{{< steps >}}
1. 볼에 강력분 300g, 드라이이스트 5g, 따뜻한 우유 150ml, 계란 1개, 연유 3큰술을 넣고 한 덩어리로 뭉쳐질 때까지 치댑니다. **우유는 차가우면 안 부풉니다.** 손을 담갔을 때 미지근한 정도(35~40℃)면 됩니다.

2. 녹인 버터 30g을 넣고 반죽이 매끈해질 때까지 **10분** 치댄 다음, 따뜻한 곳에서 1차 발효합니다. 버터는 처음부터 넣지 말고 꼭 나중에 넣으세요.

3. 발효된 반죽을 길게 늘려 돌돌 말아 밥솥 내솥에 모양을 잡아 넣습니다. **돌돌 말아야** 뜯을 때 결이 쭉쭉 갈라집니다.

4. 밥솥 만능찜 기능으로 **40분** 노릇하게 굽습니다. 중간에 뚜껑을 열지 말고 그냥 두세요.

5. 다 구워지면 표면에 연유를 살짝 발라 마감합니다. **뜨거울 때 발라야** 스며듭니다 — 이 마지막 연유가 진짜 포인트입니다.
{{< /steps >}}

{{< tip title="실패 없이 구우려면" >}}
- **1차 발효는 40~60분**, 반죽이 처음의 2배로 부풀면 끝입니다. 손가락에 밀가루를 묻혀 반죽을 찔렀을 때 자국이 그대로 남으면 다 된 것이고, 스르륵 메워지면 더 두세요. 실온이 낮은 겨울에는 시간이 더 걸립니다.
- 우유를 데울 때 **50℃를 넘기지 마세요.** 이스트가 죽어서 아예 안 부풉니다. 전자레인지에 20~30초면 충분합니다.
- 내솥에 넣기 전 **버터나 기름을 얇게 발라두면** 다 구운 뒤 빵이 깔끔하게 빠집니다.
- 더 폭신하게 만들고 싶다면, 내솥에 넣은 뒤 밥솥 **보온 기능으로 20분** 두어 2차 발효를 시키고 나서 만능찜을 돌리세요. 원래 순서대로 바로 구워도 되지만, 한 단계 넣으면 결이 확실히 부드러워집니다.
- 만능찜 기능이 없는 밥솥이라면 **백미 취사를 두 번** 돌리면 비슷하게 됩니다. 한 번으로는 속이 덜 익습니다.
- 다 구운 빵은 식힘망에 올려 완전히 식힌 뒤 자르세요. 뜨거울 때 자르면 속이 눌려 뭉칩니다.
{{< /tip >}}
