익혀 먹는 [배추김치]({{< relref "/recipes/baechu-kimchi" >}})와 달리, 짧게 절여 바로 무쳐 먹는
겉절이입니다. 그래서 양념도 훨씬 간단해요. 무채도 찹쌀풀도 없이 고춧가루와 액젓,
마늘만으로 끝납니다. **절임 소금 3큰술**은 오래 두지 않고 바로 먹는 것을 전제로 한 양입니다.

## 재료

{{< ingredients title="절임" >}}
- 배추 1통 (약 2.5kg)
- 소금 3큰술
{{< /ingredients >}}

{{< ingredients title="양념" >}}
- 고춧가루 4~5큰술
- 멸치액젓 3큰술 (또는 까나리액젓)
- 다진 마늘 1큰술
- 매실액 1.5~2큰술 (또는 설탕·올리고당)
- 다진 생강 1/2작은술 (생략 가능)
- 통깨 1큰술
- 쪽파 또는 대파 약간 (선택)
{{< /ingredients >}}

## 만드는 법

{{< steps >}}
1. 배추를 4~5cm 크기로 큼직하게 썹니다. 겉절이는 포기째 하지 않고 처음부터 먹기 좋게 자릅니다.

2. 소금 3큰술을 고루 뿌려 **30~40분** 절입니다. 중간에 한 번 위아래를 뒤집어 줍니다.

3. 흰 줄기가 뻣뻣하게 부러지지 않고 휘면 다 절여진 겁니다.

4. 찬물에 가볍게 헹구고 **체에 받쳐 물기를 충분히 털어냅니다.** 물기가 남으면 양념이 묽어져 싱거워집니다.

5. 볼에 양념 재료를 모두 넣고 잘 섞습니다.

6. **버무리기 전에 양념을 살짝 찍어 간을 봅니다.** 싱거우면 액젓이나 소금을 아주 조금씩 더합니다. 배추와 섞이면 간이 옅어지니 약간 짜다 싶은 정도가 맞습니다.

7. 절인 배추에 양념을 넣고 **살살** 버무립니다. 세게 치대면 숨이 죽어 물러집니다.

8. 쪽파와 통깨를 넣고 한 번 더 가볍게 섞어 바로 냅니다.
{{< /steps >}}

{{< tip title="더 맛있게 무치려면" >}}
- **새우젓을 섞으면 감칠맛이 확 삽니다.** 액젓 3큰술을 다 쓰는 대신 **액젓 2큰술 + 새우젓 1큰술** 조합으로 시작해 보세요. 새우젓은 짜니 **건더기만 곱게 다져** 넣어야 국물이 깔끔합니다. 넉넉히 넣고 싶으면 1.5큰술까지.
- **밀가루풀은 넣을 때와 아닐 때가 다릅니다.** 바로 먹을 겉절이라면 없어도 깔끔하고 충분합니다. 며칠 두고 익혀 먹을 거라면 넣으세요 — 양념이 배추에 착 붙고 유산균의 먹이가 되어 숙성을 돕습니다.
- 풀 만드는 법: 물 100ml에 밀가루 1큰술을 잘 풀어 냄비에 끓이거나 전자레인지에 1분 돌려 죽처럼 걸쭉하게 만든 뒤 **완전히 식혀서** 씁니다. 양념장에 2~3큰술이면 적당합니다. 풀을 넣으면 간이 살짝 연해지니 액젓이나 소금을 아주 조금 보태세요.
- 고춧가루는 4큰술로 시작해 색을 보고 5큰술까지 올리세요. 고춧가루마다 매운 정도와 색이 크게 다릅니다.
- 겉절이는 만든 날이 가장 맛있습니다. 이틀 넘게 둘 거라면 처음부터 풀을 넣고 담그는 편이 낫습니다.
{{< /tip >}}
