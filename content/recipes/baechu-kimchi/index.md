김치는 **절이기에서 이미 절반이 끝납니다.** 덜 절여지면 양념이 안 배고 물이 생기고,
과하게 절여지면 짜고 배추가 흐물거립니다. 아래 시간과 농도는 배추 1포기(2.5kg) 기준이고,
양이 바뀌면 소금물과 양념을 같은 비율로 늘리면 됩니다.

## 재료

{{< ingredients title="절임" >}}
- 배추 1포기 (2.5kg)
- 천일염 1컵 (150g) — 소금물용
- 천일염 1/2컵 (75g) — 줄기에 뿌리는 용도
- 물 2L
{{< /ingredients >}}

{{< ingredients title="찹쌀풀" >}}
- 물 300ml
- 찹쌀가루 2큰술
{{< /ingredients >}}

{{< ingredients title="양념" >}}
- 고춧가루 1.5컵 (120g)
- 무 1/2개 (400g)
- 쪽파 100g
- 멸치액젓 5큰술
- 새우젓 2큰술 (건더기째 다져서)
- 다진 마늘 4큰술
- 다진 생강 1작은술
- 양파 1/2개
- 배 1/2개
- 설탕 1큰술 (또는 매실청 2큰술)
{{< /ingredients >}}

## 만드는 법

### 1단계 — 절이기

{{< steps >}}
1. 배추 밑동에 칼집을 **1/3 깊이만** 넣고 손으로 쪼개 4등분합니다. 칼로 끝까지 자르면 잎이 잘려 부스러기가 많이 나옵니다.

2. 물 2L에 천일염 1컵을 녹여 소금물을 만들고, 배추를 통째로 담갔다 건집니다.

3. 건진 배추의 **두꺼운 줄기 사이사이에만** 남은 천일염 1/2컵을 뿌립니다. 잎 쪽은 얇아서 금방 절여지니 뿌리지 않습니다.

4. 남은 소금물을 붓고 무거운 것으로 눌러 **6시간** 절입니다. 2시간마다 위아래를 바꿔줍니다.

5. 흰 줄기를 반으로 구부렸을 때 **부러지지 않고 휘면** 다 절여진 겁니다. 아직 뚝 부러지면 1시간씩 더 둡니다.

6. 찬물에 **세 번** 헹구고, 자른 단면이 아래로 가게 채반에 엎어 30분~1시간 물기를 뺍니다. 이 단계를 건너뛰면 김치에서 물이 나옵니다.
{{< /steps >}}

### 2단계 — 양념 만들기

{{< steps >}}
1. 냄비에 물 300ml와 찹쌀가루 2큰술을 넣고 잘 풀어 중불에서 저어가며 끓입니다. 걸쭉해지면 불을 끄고 **완전히 식힙니다.** 뜨거운 상태로 쓰면 고춧가루 색이 죽습니다.

2. 무는 0.3cm 두께로 채 썰고, 쪽파는 4cm 길이로 자릅니다. 양파와 배는 갈아둡니다.

3. 큰 볼에 무채와 고춧가루 1.5컵을 넣고 먼저 버무려 **10분 둡니다.** 무에서 나온 수분이 고춧가루를 불려 색이 곱게 납니다.

4. 식힌 찹쌀풀, 멸치액젓, 새우젓, 다진 마늘, 다진 생강, 간 양파와 배, 설탕을 모두 넣고 섞습니다.

5. 간을 봅니다. **약간 짜다 싶은 정도**가 맞습니다 — 배추와 섞이면 싱거워집니다.

6. 마지막에 쪽파를 넣고 숨이 죽지 않게 살살 섞습니다.
{{< /steps >}}

### 3단계 — 버무리고 익히기

{{< steps >}}
1. 배추 한 쪽을 잡고 **겉잎부터 한 장씩 들추며** 양념을 바릅니다. 줄기 쪽은 두껍게, 잎 쪽은 얇게.

2. 다 바른 배추는 잎 쪽으로 줄기를 감싸 동그랗게 말고, 겉잎 한 장으로 전체를 감쌉니다.

3. 통에 **꾹꾹 눌러 담되 80%까지만** 채웁니다. 익으면서 국물이 올라와 넘칩니다.

4. 양념 볼에 물 반 컵을 부어 헹군 뒤 그 물을 김치 위에 붓고, 남은 겉잎으로 덮어 공기를 막습니다.

5. 실온(20℃ 기준)에 **1~2일** 두어 익힙니다. 국물에 기포가 올라오고 새콤한 냄새가 나면 다 익은 겁니다.

6. 냉장고나 김치냉장고로 옮깁니다.
{{< /steps >}}

{{< tip title="실패 없이 담그려면" >}}
- **소금은 반드시 천일염.** 정제염은 같은 무게여도 훨씬 짜고, 절임 속도가 달라 시간 계산이 어긋납니다.
- 여름에는 실온 숙성을 **반나절로 줄이세요.** 25℃가 넘으면 하루 만에 시어집니다. 반대로 겨울 베란다처럼 10℃ 아래면 3~4일 걸립니다.
- 젓갈을 뺀 채식 김치도 됩니다. 멸치액젓·새우젓 대신 **국간장 3큰술 + 소금 1큰술**을 쓰고, 표고버섯 우린 물을 찹쌀풀에 섞으면 감칠맛이 보완됩니다.
- 국물이 부족해 보여도 물을 더 붓지 마세요. 하루 지나면 배추에서 물이 나와 잠깁니다.
- 익은 김치가 시어지면 그대로 [김치찌개]({{< ref "/recipes/kimchi-jjigae" >}})나 [김치볶음밥]({{< ref "/recipes/kimchi-bokkeumbap" >}})으로 쓰면 됩니다. 신 김치일수록 오히려 잘 맞습니다.
{{< /tip >}}
