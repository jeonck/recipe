애호박은 수분이 많아 **오래 볶으면 흐물흐물해집니다.** 총 7~8분 안에 끝내세요.
간은 소금 대신 새우젓으로 — 감칠맛이 확실히 다릅니다.

## 재료

{{< ingredients >}}
- 애호박 1개
- 양파 1/2개
- 식용유 1큰술
- 새우젓 1/2큰술
- 다진 마늘 1/2큰술
- 물 2큰술
{{< /ingredients >}}

## 만드는 법

{{< steps >}}
1. 애호박은 반달 모양으로 0.5cm 두께로 썰고, 양파는 굵게 채 썹니다.

2. 새우젓은 건더기를 잘게 다집니다. 국물째 넣으면 짜고 국물이 지저분해집니다.

3. 팬에 식용유 1큰술을 두르고 중불에서 양파를 2분 볶습니다.

4. 애호박을 넣고 2분 더 볶습니다.

5. 새우젓, 다진 마늘, 물 2큰술을 넣고 **3~4분** 익힙니다. 애호박이 반투명해지면 다 된 겁니다.
{{< /steps >}}

{{< tip >}}
- 새우젓이 없으면 소금 1/2작은술로 대체하되, 마지막에 참기름 1/2큰술을 더하면 허전함이 덜합니다.
- 애호박을 썰어 소금에 5분 절였다 물기를 짜고 볶으면 더 쫄깃합니다. 시간이 있을 때만.
- 마른 새우 한 줌을 3번 단계에서 함께 볶으면 감칠맛이 훨씬 진해집니다.
- 물이 많이 생기면 뚜껑을 열고 센 불로 30초 날리세요.
{{< /tip >}}
