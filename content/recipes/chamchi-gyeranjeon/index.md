참치 기름을 덜 빼면 반죽이 질척해져 부칠 때 퍼집니다. **숟가락으로 꾹 눌러**
기름을 최대한 짜내세요. 부침가루 1큰술은 반죽을 잡아주는 역할입니다.

## 재료

{{< ingredients >}}
- 참치 1캔 (100g, 기름 뺀 것)
- 계란 2개
- 다진 양파 2큰술
- 부침가루 1큰술
- 식용유 1큰술
{{< /ingredients >}}

## 만드는 법

{{< steps >}}
1. 참치는 체에 밭치고 **숟가락으로 눌러** 기름을 최대한 짜냅니다.

2. 양파는 아주 잘게 다집니다. 굵으면 부칠 때 흩어집니다.

3. 볼에 참치, 계란 2개, 다진 양파, 부침가루 1큰술을 넣고 골고루 섞습니다.

4. 팬에 식용유 1큰술을 두르고 **중약불**로 달굽니다.

5. 반죽을 한 숟가락씩 떠 올려 동그랗게 펼칩니다. 2분간 건드리지 말고 두었다가 뒤집습니다.

6. 뒤집어서 2분 더, 속까지 익도록 충분히 부칩니다.
{{< /steps >}}

{{< tip >}}
- 센 불에서 부치면 겉만 타고 속이 안 익습니다. 중약불로 천천히.
- 뒤집을 때 반죽이 흩어지면 부침가루를 1/2큰술 더 넣으세요.
- 당근이나 대파를 잘게 다져 더하면 색이 예쁩니다.
- 케첩이나 초간장을 곁들이면 좋습니다. 도시락 반찬으로도 좋아요.
{{< /tip >}}
